Tally: a shared budget that remembers

Walrus Memory + Tatum on Sui · Walrus x Tatum “Total Recall” entry, Consumer Finance track · Astra Trading Company

What it does

Tally splits group expenses, tracks who owes what, and learns each group's habits: category limits, who usually pays, recurring bills. Users never see a wallet.

How it uses Walrus + Tatum

Every expense and learned preference is written as an encrypted memory to Walrus via Walrus Memory, under a MemWalAccount created server-side with a dedicated delegate key. Recall is semantic, so “are we over on groceries?” finds the learned limit plus recent spend.

Tatum's Sui RPC reads on-chain USDC settlements so a repayment closes the debt automatically. Tatum's Sui mainnet gateway (sui-mainnet.gateway.tatum.io, GraphQL interface, x-api-key auth) powers the on-chain side: balance() reads a member's SUI/USDC balance and settlements() scans transactions touching the group address and keeps positive native-USDC balance changes. Tally.reconcile() matches each sender to a member, records the repayment in the ledger, and writes a “Settlement” memory to Walrus, so the group's debts close themselves and the history is remembered across sessions.

How it learned over time

The useful part is not just storing expenses — it is that a later learnLimit changes what the assistant says when the same question comes back.

Before any category limit was remembered, asking “are we over on entertainment?” only surfaced the raw ledger line: Blake paid $90 for concert tickets (split with Casey and Drew). There was no ceiling in memory, so the honest reply was just the spend — no warning, because the app had nothing to warn against.

After the group preference was written (learnLimit('entertainment', 100) → “Learned preference: group monthly limit for entertainment is 100 USD.”), the same question on mainnet now returns both memories side by side. Re-verified 6 Nov 2026 (Asia/Dubai) against the live account: semantic recall for entertainment limit ranked the $100 monthly limit first and the $90 concert expense next. Combined with the in-process ledger, that flips the product copy from a neutral spend summary to an approaching-limit warning — $90 of $100 this month — without anyone re-teaching the bot. Dining stays calm on the same path ($32 of the learned $150 limit). Groceries, utilities, and the first-Monday USDC settlement habit behave the same way: once the preference is a Walrus memory, every future session recalls it.

That before/after is the whole pitch for Walrus Memory here: the warning text changes because history was written once, encrypted, and recalled semantically — not because we hard-coded a rules engine per group.
